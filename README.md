# 水下考古标签发放补换台

直接打开 `index.html` 使用（三个业务文件需与页面同目录）。标签被泥沙磨掉后，在这里登记、发放、换发与重印。

## 业务规则

- **标记与标签分离**：一个潜次里，一张标签编号只发给一个标记；同潜次编号重复时发不出去。
- **登记**：点击沉船平面图选位置，填写编号、领用人、类型、潜次、深度并上传照片，发放首张现行标签。
- **换牌**：旧牌的领用人、领用时刻原样冻结保留，新牌接到同一标记；旧牌可在存档里查到，但不出现在当前清单。
- **资料更正**：更正前先把整张现行清单留档快照，随后旧牌失效并转为"待重印"。
- **重印新发**：失效旧牌继续留档可查，重印的新牌成为现行牌（允许沿用原编号）。
- 当前清单只显示现行牌；筛选、潜次时间线、JSON 导出照常可用，存档页可按编号/潜次/领用人搜索旧牌与历史清单。

## 文件划分

| 文件 | 职责 |
| --- | --- |
| `tags.js` | 标签判定：唯一性校验、发放、换牌、更正失效、重印 |
| `archive.js` | 存档：旧牌留档查询、更正前清单快照 |
| `app.js` | 页面操作：表单、按钮动作、渲染、筛选、时间线、JSON 导出 |

数据保存在浏览器 `localStorage`（键 `zfl30TagDesk`），旧版 `zfl30Marks` 数据首次打开时自动迁移。
