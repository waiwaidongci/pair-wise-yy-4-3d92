# 水下考古标签发放补换台

标签被泥沙磨掉后凭记忆找记录不再可靠——本页面是潜水队的标签**发放 / 换牌 / 资料更正**工作台。直接打开 `index.html` 即可使用（数据存浏览器 localStorage，无需构建）。

## 业务文件划分

| 文件 | 职责 |
| --- | --- |
| `js/tags.js` | **标签判定**：发放、同潜次编号去重、换牌、资料更正失效、重印领用等纯业务规则，不碰 DOM |
| `js/archive.js` | **存档**：资料更正前把当前清单整体快照留档（只读） |
| `js/app.js` | **页面操作**：平面图选点、表单与照片、各视图渲染、筛选/搜索、时间线、存储与 JSON 导出 |

## 规则

- **发放**：每个潜次里一张标签编号只对应一个标记；登记编号、类型、潜次、深度、领用人和照片。同一潜次编号重复时发不出去（已换下/已失效的旧编号也占用，防止误重发）。
- **换牌**（标签磨损）：旧牌的**领用人和发放时刻原样保留**，新牌接到同一标记；旧牌在「标签记录」里可查，但不进入当前清单。
- **资料更正**：旧牌**失效并转入待重印队列**（编号沿用），更正前的当前清单整体**存档**；在「待重印队列」登记领用人后，重印牌接回同一标记，标记回到当前清单。
- 旧版单牌数据（`zfl30Marks`）首次打开时自动迁移为新结构。

## 视图

- **当前清单**：只列现牌有效的标记（待重印中的标记在地图上以黄点标出，但不进清单）。
- **潜次时间线**：按潜次分组的发放记录。
- **标签记录**：现牌 + 旧牌（已换牌 / 已失效）全量可查。
- **待重印队列**：资料更正后等待重印领用的标签。
- **存档清单**：历次更正前的清单快照，只读。

类型筛选、编号/潜次/领用人搜索和右上角「导出JSON」（含标记、各代标签、待重印、存档）照常可用。
